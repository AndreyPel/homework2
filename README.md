# Домашнее задание к работе 2

## Условие задачи

Известно, что бригада строителей может построить дом за х дней. Определить сколько получит бригада за строительство дома, если известно, что при его строительстве в n дней их зарплата равна S рублей, каждый день просрочки уменьшает ее на 50/n %, а досрочная сдача увеличивает на эту же сумму.

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **Начало**
2. Объявить константы:
   - PERCENT_BASE = 50,
   - HUNDRED = 10

3. Задать исходные данные: 
   - x (план)
   - n (факт)
   - S (базовая зарплата)
4. Вычислить разницу 
   - d = x - n
5. Вычислить изменение зарплаты за каждый день: 
   - day = PERCENT_BASE / n
6. Вычислить итоговую сумму: 
   - W = S * (1.0 - d * PERCENT_BASE / (HUNDRED * n))
7. Вывести результаты с подстановкой всех значений 
8. **Конец**
